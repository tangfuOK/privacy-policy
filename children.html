儿童隐私保护声明

更新日期：2026年11月8日
生效日期：2026年11月8日

本应用非常重视儿童个人信息的保护。根据《中华人民共和国个人信息保护法》、《儿童个人信息网络保护规定》等相关法律法规的要求，本应用制定本儿童隐私保护声明。

如果您是未满14周岁的未成年人，请您在监护人的陪同下仔细阅读本声明，并在征得监护人的同意后使用我们的产品或服务。

如果您是儿童的监护人，请您仔细阅读本声明，并决定是否同意本声明以及您的孩子使用我们的产品或服务。

一、我们收集的信息说明

我们遵循正当必要、知情同意、目的明确、安全保障、依法利用的原则。

我们郑重承诺：不收集儿童的姓名、年龄、身份证号码、住址、电话号码、账户信息、位置信息、照片、语音等任何可识别个人身份的信息。

我们仅收集以下非个人信息用于改善应用质量和稳定性：

1. 应用基本信息
为了识别和分析应用版本问题，我们会收集：
• 应用包名
• 应用版本号
• 开发者信息

2. 应用运行日志
为了分析和修复应用问题，提高应用稳定性，我们会收集：
• 崩溃日志（记录应用崩溃时的技术信息）
• 启动日志（记录应用启动状态）
• 能耗日志（记录应用能耗情况）
• 诊断日志（记录应用运行异常信息）

以上信息均为应用运行的技术数据，不包含任何儿童个人身份信息。

二、我们如何使用收集的信息

我们收集的信息仅用于以下技术性目的：

1. 分析和修复应用崩溃问题，提高应用稳定性
2. 优化应用启动速度和运行性能
3. 分析应用能耗，降低电池消耗
4. 诊断应用运行异常，改善用户体验
5. 进行版本迭代和质量管理

我们不会将这些技术数据用于任何商业营销、用户画像或其他与改善应用质量无关的目的。

三、信息的存储和安全

1. 存储地点
我们收集的应用运行数据存储在中华人民共和国境内。

2. 存储期限
应用运行日志仅保留30天，超过期限后将自动删除。应用基本信息仅用于版本管理，不会长期存储。

3. 安全措施
我们采用符合业界标准的安全防护措施，包括：
• 数据传输加密
• 访问权限控制
• 定期数据清理
• 技术安全审计

4. 匿名化处理
所有收集的数据均经过匿名化处理，不与任何个人身份信息关联。

四、信息的共享、转让和披露

我们郑重承诺：

1. 不共享
我们不会与任何第三方共享所收集的应用运行数据。这些数据仅在我们内部用于技术分析和改进。

2. 不转让
我们不会将收集的数据转让给任何公司、组织和个人。

3. 不公开披露
我们不会公开披露收集的数据，除非基于法律法规、法律程序或政府主管部门的强制性要求。

4. 不用于商业目的
所收集的技术数据仅用于改善应用质量，不会用于任何商业营销、广告推送或盈利目的。

五、监护人的权利

作为儿童的监护人，您享有以下权利：

1. 知情权
您有权了解我们收集哪些信息以及如何使用这些信息。

2. 拒绝权
您可以选择不同意我们收集应用运行数据，但这可能影响我们改进应用质量的能力。

3. 查询权
您可以随时向我们查询所收集数据的类型和用途。

4. 投诉权
如果您认为我们的数据收集行为不当，您有权向我们投诉或向相关监管部门举报。

由于我们不收集可识别个人身份的信息，因此无需提供个人信息的访问、更正或删除功能。所有技术数据在30天后会自动删除。

如需行使上述权利或有任何疑问，您可以通过以下方式联系我们：
邮箱：tinatian_ok@foxmail.com

六、我们的保护措施

1. 最小化原则
我们严格遵循数据最小化原则，仅收集必要的技术数据，不收集任何可识别儿童个人身份的信息。

2. 透明原则
我们在本声明中详细说明收集的信息类型和用途，确保监护人充分了解。

3. 安全原则
我们采用加密传输、访问控制等技术手段保护数据安全。

4. 自动清理
应用运行日志自动保留30天后删除，无需监护人手动操作。

5. 持续改进
我们会持续关注儿童隐私保护的法律法规变化，及时更新我们的保护措施。

七、本声明的更新

我们可能会适时修订本声明的内容。未经您明确同意，我们不会削减您和您的孩子按照本声明所应享有的权利。

我们会通过应用内通知、弹窗提示等显著方式告知您更新的内容。

对于重大变更，我们会重新征得监护人的明确同意。

本声明所指的重大变更包括但不限于：
• 开始收集儿童个人身份信息
• 收集数据的类型发生变化
• 数据的使用方式发生重大变化
• 数据的共享、转让或公开披露政策发生变化

如本声明与《隐私政策》存在不一致之处，以本声明为准。

十、特别说明

1. 我们不要求儿童提供任何个人信息即可使用本应用的基本功能。

2. 我们不会基于儿童的个人信息进行任何形式的用户画像、个性化推荐或定向广告。

3. 我们收集的应用运行数据完全匿名，即使数据泄露也无法识别任何儿童的个人身份。

4. 监护人有权随时要求我们停止收集应用运行数据，请通过邮箱联系我们。

我们致力于为儿童提供安全、健康的应用使用环境，感谢您的信任与支持！
